## 📌 Описание проекта

Демонстрационный репозиторий, в котором показан **код с ошибкой** и его **исправленная версия**. Проект создан в учебных целях для отработки навыков работы с GitHub и понимания типичных ошибок в программировании.

---

## 📁 Структура репозитория
bug-vs-fix-demo/
├── README.md # Описание проекта
├── buggy_code.py # Код с ошибками
└── fixed_code.py # Исправленный код

---

## 🐞 Файл `buggy_code.py` — код С ОШИБКОЙ

В данном файле специально допущены **две типичные ошибки**:

| № | Ошибка | Причина |
|---|--------|---------|
| 1 | `ZeroDivisionError` | Деление на `len(numbers)`, когда список пустой |
| 2 | `IndexError` | Обращение к `numbers[0]` при пустом списке |

**Запуск:**
```bash
python buggy_code.py
